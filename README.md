## 🧩 页面JS逻辑说明
1. 下载计数：使用 `localStorage` 键名 `jinenge_download_click_count`，点击下载自增计数，页面不显示数字
2. 返回按钮 `goBack()`：向父页面发送 `postMessage` 消息 `{"type":"backPage"}`
3. 拦截浏览器物理返回键（popstate），触发自定义返回事件
4. 下载跳转函数 `go(path)`：先计数，再跳转链接
